Code

Public research codes on GitHub (github.com/roger2b).

EFTofLSS_nu — Mathematica notebooks for the tree-level bispectrum of large-scale structure with massive neutrinos, from de Belsunce & Senatore (2019).

likelihood-approximations — Python code that approximates a likelihood from the moments of the data, developed for the large-angle Planck polarization analysis in de Belsunce et al. (2021).

Bayesian-parametric-fitting — Fast Bayesian extraction of a cosmological signal from multi-frequency maps, used to test for spectral-index variations in polarized foregrounds in de Belsunce et al. (2022).

smooth_covmat — Fortran code that builds smooth covariance matrices from the Planck hit-count maps.

MAPLE — Maximum a posteriori estimator for the 3D Lyman-α forest power spectrum and its covariance, written in JAX with Benjamin Horowitz and Zarija Lukić (Horowitz, de Belsunce & Lukić 2024).
